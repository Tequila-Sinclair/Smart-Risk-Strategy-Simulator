# Smart-Risk-Strategy-Simulator
設計目標：專為加密貨幣與外匯交易者（尤其是使用 SMC / ICT 價格行為策略者）設計的單頁 Web App，協助交易員在下單前快速進行風險管理計算，並透過互動式隨機市場模擬器進行策略測試。

1. 使用者痛點與發想背景
許多新手交易員在進行價格行為（Price Action）交易時，常因缺乏明確的倉位計算而導致過度槓桿或單筆虧損過大。

市面上的風控計算機介面繁雜且缺乏互動性。

希望建立一個兼具「精確計算」與「動態模擬互動」的現代化工具。

2. 功能規格細節 (Functional Specifications)
輸入參數區：

帳戶資本 (Account Capital)：預設 10,000 USDT。

風險百分比 (Risk Percentage)：預設 1%（支援小數點輸入）。

進場價 (Entry Price)、停損價 (Stop Loss)、指盈價 (Take Profit)。

即時風控計算引擎：

建議倉位大小 (Position Size) = (帳戶資本 * 風險%) / |進場價 - 停損價|

單筆預期虧損 (Risk Amount) = 帳戶資本 * 風險%

盈虧比 (Risk-to-Reward Ratio, R:R) = |指盈價 - 進場價| / |進場價 - 停損價|

互動式價格行為模擬區 (Price Action Simulator)：

提供「做多 (Long)」與「做空 (Short)」互動按鈕。

點擊後由 JavaScript 進行隨機動態價格波動演算法模擬。

系統即時判斷是否到達止盈/止損，並跳出綠色獲利或紅色停損的高對比狀態標籤與文字回饋。

3. 介面與技術規格 (Technical Specifications)
單一檔案設計：全網頁整合於 index.html，無額外依賴包。

CSS 框架：採用 Tailwind CSS (Via CDN)，實現現代 Dark Mode 深色質感。

響應式佈局：支援 Desktop 雙欄視角與 Mobile 單欄順暢滑動。
